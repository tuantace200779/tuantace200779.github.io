## Publish this as your GitHub user site

1. Create a **public** repository named exactly `tuantace200779.github.io` under the account `tuantace200779`.
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root level, not inside another nested folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. After deployment, visit https://tuantace200779.github.io/.

GitHub's official quickstart specifies that a user site repository must be named `<username>.github.io`; the default user-site URL is `https://<username>.github.io/`.
